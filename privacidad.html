Política de privacidad / Privacy Policy

Última actualización: 31 de octubre de 2026.

Datos de Google a los que se accede

JAZIM solo accede a Google Drive con el permiso https://www.googleapis.com/auth/drive.file, para crear y leer los archivos de copia de seguridad que él mismo crea dentro de la carpeta «JAZIM». No accede a ningún otro archivo, contacto, correo ni dato de la cuenta de Google.

Cómo se usan y almacenan

  • Las copias de seguridad se cifran antes de subirse con una clave que solo conoce el propietario. Google solo almacena archivos cifrados.
  • La autorización (token de acceso) se guarda cifrada en el servidor privado del propietario. No se envía a terceros.
  • JAZIM no usa los datos de Google para publicidad, análisis, perfiles ni entrenamiento de modelos, y no los vende ni comparte con nadie.
  • El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Control y eliminación

El propietario puede revocar el acceso en cualquier momento en myaccount.google.com/permissions y borrar la carpeta «JAZIM» de su Drive.

Summary in English

JAZIM accesses Google Drive only with the drive.file scope to create and read the encrypted backup files it creates in a "JAZIM" folder. Backups are encrypted before upload with a key known only to the owner. The authorization token is stored encrypted on the owner's private server. Data is not shared, sold, or used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The owner can revoke access at myaccount.google.com/permissions. Contact: see above.
